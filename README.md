# ProGym

App per tracciare gli allenamenti in palestra: schede, serie, carichi, record personali, progressi e misurazioni.

**Provala qui:** https://giulianotesta.github.io/Progym/

## Sul telefono

1. Apri il link in Safari (iPhone) o Chrome (Android).
2. Condividi → **Aggiungi alla schermata Home**: si apre a schermo intero, come un'app.

## Cosa fa

- Schede di allenamento a giorni (Push / Pull / Legs…), con riordino degli esercizi
- Catalogo di oltre 700 esercizi con filtri per muscolo e attrezzatura
- Registrazione delle serie con timer di recupero
- Record personali, grafici di volume e progressi, calendario
- Misurazioni corporee, kg / lb, tema scuro e chiaro, italiano e inglese
- Esportazione dello storico in CSV

## Da sapere

- I dati restano salvati nel browser del dispositivo: funziona anche offline.
- Login e sincronizzazione tra dispositivi non sono attivi in questa versione web.
- Questa repository contiene solo la versione web compilata (Flutter). Il codice sorgente non è qui.

Catalogo esercizi: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense).
